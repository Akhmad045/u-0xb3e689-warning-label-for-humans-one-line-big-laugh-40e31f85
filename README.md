## The line

> CAUTION: Will keep pressing 'Remind me later' until the deadline it was reminding them about has already passed.

One line, 112 characters: the safety warning label that should come printed
on every human being. It reads like a real printed label, names a flaw
everyone recognises in themselves — snoozing reminders until it is too
late — and lands its punch in the last few words.

## How it works

`main.py` (Python 3.13, standard library only, no network) writes the line
to `/output/entry.txt` and validates it first: a single non-blank line of
1–160 UTF-8 characters, verified to round-trip exactly from the written file.

```sh
python3 main.py
```
